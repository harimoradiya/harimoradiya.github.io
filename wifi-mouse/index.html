Setup Guide

Get Started in 4 Simple Steps

1

Install Server

Download and install the WiFi Mouse Server on your computer (Windows, macOS, or Linux). Run with admin privileges and note the IP address.

2

Install App

Download WiFi Mouse from Play Store on your Android device. Grant network permissions and ensure both devices are on the same WiFi.

3

Connect Devices

Open the app, tap Auto Connect, or scan the QR code from your server. Your device will appear automatically.

4

Start Controlling

Slide to move cursor, tap for clicks, two-finger swipe to scroll. Access keyboard and app launcher from the menu.
