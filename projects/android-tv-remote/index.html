Key Architectural Features

Zero Ads & Zero In-App Purchases

100% community-focused utility built for speed and utility. Free forever with no tracking or paywalls.

Instant Wi-Fi Auto-Discovery

Uses mDNS and Network Service Discovery (NSD) to instantly locate Android TVs on your local network without manual IP entry.

Low Latency Socket Protocol

Direct socket communication protocol for instant tactile response during D-pad navigation and fast typing.

Modern Jetpack Compose UI

Clean Material You user interface built with Kotlin Coroutines and Jetpack Compose for smooth 60fps animations.
